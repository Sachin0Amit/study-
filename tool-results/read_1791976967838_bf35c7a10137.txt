     7→## Architecture quick reference (for all agents)
     8→
     9→- **Library data model** (src/data/library.ts): `Subject → BookMeta → ChapterMeta → SectionMeta`
    10→  - LIBRARY_SUBJECTS, LIBRARY_BOOKS, LIBRARY_CHAPTERS, LIBRARY_SECTIONS exported arrays
    11→  - Chapter: `{ id, bookId, number, title, shortTitle, description, icon, pages, interactiveKey }`
    12→  - Section: `{ id, chapterId, number, title, description }` (id like `bookId-chN-sM`)
    13→- **Metadata files**: src/data/library-parts/*.ts export `X_CHAPTERS: ChapterMeta[]` + `X_SECTIONS: SectionMeta[]`
    14→- **Lesson content**: src/data/content/*.ts export `SectionContent[]` (intro, objectives, concepts, examples, keyTakeaways, quiz). contentMap lookup by sectionId. Sections WITHOUT content render fine (optional chaining) but show only header.
    15→- **Icons**: lucide icon names via chapterIcons map in src/components/app/chapter-icon.tsx — CHECK available icon keys before using.
    16→- **Interactive keys**: registry in src/components/interactives/registry.tsx — reuse existing keys like 'js-playground', 'curve-lab', etc.
    17→- **API routes**: /api/library returns all metadata. No DB needed for library (static data). DB used for progress/notes/quiz attempts/exams only.
    18→- **Exams requested by user**: IIT JEE MAINS, IIT ADVANCED, SAT, DRDO, ENGINEERING EXAM CSE/ECE/EE/ME, GATE CS — all syllabus topics + subtopics must be added to the subject library in detail.
